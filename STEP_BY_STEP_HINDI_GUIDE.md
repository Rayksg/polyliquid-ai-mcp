# PolyLiquid AI — Aasaan Step-by-Step Guide (Bina Coding Ke)

## Aapke Liye Maine Kya-Kya Bana Diya Hai?
1. **`index.html`**: Aapki poori banayi hui Website (Hyperliquid + Polymarket Calculator, Arbitrage Scanner, aur Rule Auditor).
2. **`package.json`**: Agar aap baad mein MCP server chalana chahein to usकी सेटअप फाइल।

## Ab Aapko Sirf Yeh 3 Aasaan Kaam Karne Hain:

### Step 1: Apna Wallet Address Judwayein (2 Minute)
- Apna normal **MetaMask / Rabby / Trust Wallet** kholein aur apna **Public Address (`0x...`)** copy karke mujhe chat mein de dein (ya website ke upar wale box mein paste kar dein).
- *Dhyan rahe: Apni Private Key ya 12-word Seed Phrase kabhi kisi ko mat dein!*

### Step 2: Website Ko Free Mein Internet Par Live Karein (2 Minute, Zero Coding)
- `index.html` file ko kisi bhi free static hosting (jaise Cloudflare Pages ya Netlify Drop) par mouse se utha kar (Drag & Drop karke) daal dein.
- Turant aapko ek public website link mil jayega!

### Step 3: Free Directories Mein Link Paste Karein
- Apna Polymarket Builder Code (`polymarket.com/settings?tab=builder`, ₹0 Free) lein.
- Apni website ka link `polymart.app` ("Submit a tool") aur `mcp.so` par free mein submit kar dein.
